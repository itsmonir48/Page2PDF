        About

        Why Page2PDF?

        As students, researchers and developers, we find valuable content scattered across the web. Bookmarks get lost, websites change, and reading on screens isn't always ideal.

        Page2PDF extracts the meaningful content from any webpage — stripping away ads, navigation and pop-ups — and turns it into a beautifully formatted PDF for offline reading, printing or archiving.

        FAQ

        Questions, answered

        Is Page2PDF free?

        Yes. It's free and open source — you can use the hosted version or run it yourself with Docker.

        Which websites work best?

        Public articles, tutorials, documentation and wikis. JavaScript-heavy pages are rendered in a real browser as a fallback. Pages behind a login or paywall can't be fetched.

        Can I edit a PDF I already have?

        Yes. Upload it (or several) on its own or together with web links, then reorder, rotate, remove or duplicate pages in the editor.

        How many sources can I combine?

        Up to 20 sources per collection, and up to 50 MB per uploaded file by default. You can paste a whole list of links at once.

        How does the password protection work?

        When you set a password in the export options, the downloaded file is encrypted with AES-256. Anyone opening it will need that password.
